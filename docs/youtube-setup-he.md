# חיבור YouTube Pro Studio לערוץ היוטיוב שלך

הגדרה חד-פעמית של כ-10 דקות, ללא עלות. בסוף תקבל **Client ID**. זה מזהה ציבורי, לא סוד, ובעזרתו האפליקציה מבקשת ממך הרשאה לערוך את הסרטונים בערוץ: כותרת, תיאור, תגיות, תמונה ממוזערת, כתוביות ותגובה.

> כל מה שמוסבר כאן נעשה עם החשבון שמחזיק את ערוץ היוטיוב (למשל `studioimage1983@gmail.com`).

## 1. יצירת פרויקט ב-Google Cloud
1. נכנסים ל-<https://console.cloud.google.com/projectcreate>.
2. נותנים לפרויקט שם, למשל `YouTube Pro Studio`, ולוחצים **Create**.
3. מוודאים שהפרויקט החדש נבחר בתפריט העליון.

## 2. הפעלת YouTube Data API v3
1. נכנסים ל-<https://console.cloud.google.com/apis/library/youtube.googleapis.com>.
2. לוחצים **Enable**.

## 3. מסך ההסכמה (OAuth consent screen)
1. נכנסים ל-<https://console.cloud.google.com/auth/overview> ולוחצים **Get started**.
2. ממלאים שם לאפליקציה (למשל `YouTube Pro Studio`) ואימייל תמיכה.
3. ב-**Audience** בוחרים **External**.
4. ממלאים אימייל ליצירת קשר, מאשרים את התנאים ולוחצים **Create**.
5. בלשונית **Audience**, תחת **Test users**, לוחצים **Add users** ומוסיפים את `studioimage1983@gmail.com` (או את החשבון שמחזיק את הערוץ).
6. משאירים את האפליקציה במצב **Testing**. לא לוחצים על "Publish app".

## 4. יצירת OAuth Client ID
1. נכנסים ל-<https://console.cloud.google.com/auth/clients> ולוחצים **Create client**.
2. ב-**Application type** בוחרים **Web application**.
3. ב-**Name** כותבים שם כלשהו, למשל `YouTube Pro Studio Web`.
4. תחת **Authorized JavaScript origins** מוסיפים את שתי הכתובות:
   - `https://thebrand83-beep.github.io`
   - `http://localhost:8765`
5. את **Authorized redirect URIs** משאירים ריק.
6. לוחצים **Create** ומעתיקים את ה-**Client ID**. הוא נראה כך: `1234567890-abc123.apps.googleusercontent.com`.

## 5. הדבקה באפליקציה
1. פותחים את האפליקציה: <https://thebrand83-beep.github.io/youtube-optimizer/>
2. לוחצים ⚙️ **הגדרות**, מדביקים בשדה **Google OAuth Client ID** ולוחצים **שמור**.
3. מנתחים סרטון, עוברים ללשונית **פרסום ליוטיוב** ולוחצים **התחבר עם Google**.
4. בפעם הראשונה Google תציג את ההודעה "Google hasn't verified this app". זה תקין לאפליקציה פרטית במצב Testing. לוחצים **Continue**, מאשרים את ההרשאה וזהו.

## טוב לדעת
- **אבטחה:** אין סודות בקוד. ה-Client ID ציבורי, וההרשאה נשמרת רק בזיכרון הדפדפן לשעה אחת בכל פעם. אפשר לבטל את הגישה בכל רגע ב-<https://myaccount.google.com/permissions>.
- **גיבוי ושחזור:** לפני כל שינוי האפליקציה בודקת שהסרטון שייך לערוץ המחובר. היא שומרת את הגרסה המקורית (כולל התמונה הממוזערת) בדפדפן ומאפשרת להוריד אותה כקובץ JSON. הכפתור **שחזר מקור** מחזיר את הכותרת, התיאור, התגיות והתמונה הממוזערת, ומוחק כתוביות ותגובות שהאפליקציה הוסיפה.
- **מכסה (חינם):** YouTube Data API נותן 10,000 יחידות ביום, והמכסה מתאפסת בערך ב-10:00 בבוקר שעון ישראל.

  | פעולה | עלות |
  |---|---|
  | עדכון פרטי הסרטון | 50 |
  | תמונה ממוזערת | 50 |
  | כתוביות (לכל שפה) | 400 |
  | תגובה | 50 |

  פרסום מלא עם כתוביות בעברית עולה בערך 550 יחידות, כך שאפשר לעדכן כ-15 סרטונים ביום.
- **תמונה ממוזערת:** להעלאת תמונה מותאמת הערוץ חייב להיות מאומת בטלפון: <https://www.youtube.com/verify>.
- **תגובה מוצמדת:** יוטיוב לא מאפשר להצמיד תגובה דרך ה-API. האפליקציה מפרסמת את התגובה ונותנת קישור ישיר אליה. שם לוחצים ⋮ ואז **הצמדה**.
- **הפיכה למוצר בתשלום:** במצב Testing רק משתמשי הבדיקה שהוגדרו יכולים להתחבר (עד 100). כדי לפתוח את האפליקציה ללקוחות צריך לעבור תהליך אימות (Verification) של Google להרשאה `youtube.force-ssl`, כולל מדיניות פרטיות ודומיין מאומת.
